DISEÑO
======

Sistema de proyectos (Opción B confirmada por el usuario):
- vault/system/projects.json: lista de proyectos con metadata.
- Cada proyecto: {id, name, description, created, color}
- id = slug (ej: "fotosintesis"). name = legible ("Fotosíntesis").
- raw/<project_id>/ contiene los archivos del proyecto.
- "Archivos individuales" van a raw/individual/ (sin proyecto).

Estructura de archivos tras implementación:
```
vault/
├── raw/
│   ├── fotosintesis/          ← archivos del proyecto "Fotosíntesis"
│   │   ├── paper.pdf
│   │   └── notas.txt
│   ├── cerebro-virtual/       ← archivos del proyecto "Cerebro Virtual"
│   │   └── diagrama.png
│   └── individual/            ← archivos sin proyecto
│       └── suelto.txt
└── system/
    ├── projects.json          ← metadata de proyectos
    ├── graph.json             ← grafo de Graphify ( Parte 1)
    └── ... (archivos existentes)
```

Formato de projects.json:
```json
{
  "projects": [
    {
      "id": "fotosintesis",
      "name": "Fotosíntesis",
      "description": "Estudio del proceso fotosintético",
      "created": "2026-07-26T12:00:00Z",
      "color": "#4edea3"
    }
  ]
}
```

Si projects.json no existe, crear con {"projects": []}.

```python
import uuid
from datetime import datetime

PROJECTS_PATH = "vault/system/projects.json"

def load_projects():
    if not os.path.exists(PROJECTS_PATH):
        return {"projects": []}
    with open(PROJECTS_PATH) as f:
        return json.load(f)

def save_projects(data):
    os.makedirs("vault/system", exist_ok=True)
    with open(PROJECTS_PATH, "w") as f:
        json.dump(data, f, indent=2)

def _slugify(name):
    # ponytail: slug simple, stdlib. Si se necesita algo más robusto, usar python-slugify.
    import re
    slug = name.lower().strip()
    slug = re.sub(r'[^a-z0-9]+', '-', slug).strip('-')
    return slug or f"proyecto-{uuid.uuid4().hex[:8]}"
```

3. Nuevo endpoint: POST /api/projects

Crea un proyecto nuevo. Recibe name, description, color. Genera id + created.

```python
@app.post("/api/projects")
def create_project(name: str, description: str = "", color: str = "#4edea3"):
    data = load_projects()
    project_id = _slugify(name)
    # verificar id único
    if any(p["id"] == project_id for p in data["projects"]):
        project_id = f"{project_id}-{uuid.uuid4().hex[:4]}"
    project = {
        "id": project_id,
        "name": name,
        "description": description,
        "created": datetime.utcnow().isoformat() + "Z",
        "color": color
    }
    data["projects"].append(project)
    save_projects(data)
    os.makedirs(f"raw/{project_id}", exist_ok=True)
    return project
```

4. Nuevo endpoint: DELETE /api/projects/<project_id>

Borra un proyecto. Borra su carpeta raw/<id>/ + su entrada en projects.json.
NO borra wiki/ ni graph.json (eso se limpia con _prune_graph_json por archivo).

```python
@app.delete("/api/projects/{project_id}")
def delete_project(project_id: str):
    data = load_projects()
    data["projects"] = [p for p in data["projects"] if p["id"] != project_id]
    save_projects(data)
    # borrar carpeta raw/<id>/
    import shutil
    project_dir = f"raw/{project_id}"
    if os.path.exists(project_dir):
        # borrar cada archivo + limpiar graph.json
        for fname in os.listdir(project_dir):
            _delete_vault_item("raw", f"{project_id}/{fname}")
        os.rmdir(project_dir)
    return {"ok": True}
```
